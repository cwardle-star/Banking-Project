# Banking Financial Analysis Portfolio

This portfolio brings together four projects exploring the financial performance of Bank of America, JPMorgan Chase, Citigroup, and Wells Fargo from 2005 to 2024. I compiled financial data from SEC 10-K filings and used Excel and Python to organize the data, compare banks, and explore patterns through visualization and statistical modeling.

## Project One: Comparing Financial Performance

Compares profitability, efficiency, revenue, and net income across the four banks using financial ratios and historical trends.

## Project Two: Classifying Financial Risk

Applies financial rules to label bank-year observations as Stable or High-Risk, then evaluates how well a random forest classifier reproduces those project-defined labels.

## Project Three: Analyzing Bank Profitability

Explores relationships between financial measures and net income using linear and Ridge regression, with comparisons of model performance and limitations.

## Project Four: Identifying Financial Performance Patterns

Uses k-means and hierarchical clustering to explore similarities among bank-year observations, supported by an elbow plot, a dendrogram, and a PCA visualization.

## Tools and Skills

Excel, Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn, and SciPy. Skills demonstrated include financial data consolidation, ratio analysis, data visualization, statistical modeling, and interpretation of results.

Each project folder contains a detailed write-up, code, and charts. These projects were completed for academic learning and portfolio development.
